Dicas de Autocuidados:

Dicas simples de Autocuidados!

Aqui teremos dicas de cuidados simples e faceis para unhas, peles e cabelos.

Dicas para unhas💅🏼:

  • passe sempre base fortalecedora;
  • sempre lixe;
  • mantenha um bom tamanho;
  • faça a culticula;
  • tenha uma bom frequencia de esmaltação.

    • Dicas para peles💆🏼:

  • não durma de maquiagem;
  • lave todo dia o rosto;
  • mantenha uma rotina de skincare;
  • passe protetor solar todo dia;
  • não esprema espinhas.

    • Dicas para cabelos🪮:

  • lave mais de 3x na semana;
  • evite prender muito forte;
  • faça um cronograma capilar;
  • corte as pontas a cada 3 meses;
  • sempre use proteção termica.
